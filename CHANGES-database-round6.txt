Fixed in supabase/migrations/0118_database_round6.sql
 1. Deleting a partner failed when it had a dashboard-source terms acceptance (CHECK vs ON DELETE SET NULL). A BEFORE DELETE trigger now
    removes the email-less acceptances; rows with an application email are kept and unlinked.

    account, and a scan that is not the credited account's.

 4. scrub_account_data matched email_logs."to" case-sensitively; now lower() with an expression index.
 5. pgcrypto (0001, unused) is moved to the extensions schema if it sits in public; no-op otherwise.
 6. Indexes for four foreign keys: scans.fix_payment_id, partner_applications.partner_id, admin_audit_log.actor_id,
    scan_outcomes.story_moderated_by.
