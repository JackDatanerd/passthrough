6. BEHAVIOUR CHANGES YOU WILL NOTICE
   - A locked account's sign-in now shows the same message as a wrong password (the message now ends "After several failed attempts, sign-in pauses for a while.").
     The "Too many attempts" 429 remains for the second factor, recovery code, step-up and change-password (those need a password first).
   - Signing in with the second factor gives a new session id; audit rows 'auth.signed_in' now carry the new id. The pending session shows as revoked ('promoted') in expert_sessions.
   - A second factor code that loses a simultaneous race is a failed code and counts toward the lock.
