`throw error` / must() it. Hono only sends `instanceof Error` throws to app.onError, so every database
error escaped errorHandler: Cloudflare's own 500 page instead of JSON, no CORS/security headers, the
23505 -> 409 mapping and the "Unhandled error [cf-ray]" log never ran.

shared one 'unknown' IP bucket in local dev).
