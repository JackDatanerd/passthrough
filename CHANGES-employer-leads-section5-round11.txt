FEATURE GAPS CLOSED
G1  Aliases of a removed mailbox (+tag, Gmail dots, googlemail) are now covered by the do-not-contact list
    and by the per-address mail caps (lib/mailbox.js).
G2  The acknowledgement no longer echoes the name a stranger typed into the public form.
G3  The bounce/complaint block is visible and liftable from the leads screen; request-confirmation failures
    now say why (409 MAIL_SUPPRESSED / 429 EMAIL_LIMIT / 502 SEND_FAILED).
G4  Re-join: an address that removed ITSELF and submits again gets a "rejoin" email; /employer/rejoin adds it
    back (never for complaint/bounce/admin/unknown-reason entries).
G5  Bulk actions can cover everything a filtered list matches (with an expected-count guard).
G6  "Already told about candidates" is tracked per field; manual add accepts other fields.
G7  Each lead records consent / how it was confirmed (consent, confirmed_via).
G8  Optional keyed (HMAC) suppression hashes: SUPPRESSION_HASH_KEY / SUPPRESSION_HASH_KEY_PREVIOUS.
G9  The hourly ack retry keeps the one-click unsubscribe header (remembered API origin).
