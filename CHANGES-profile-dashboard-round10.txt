FEATURE GAPS CLOSED
G1  "Save the fixed version": on a scan whose fix was delivered, the save-profile prompt offers
    "Your resume as it was" / "The fixed version" (the person's own edits to the delivery included).
    POST /profile/save accepts source: 'original' | 'delivered', for the main profile and for
    "keep as another profile". Server-checked: only a FIX_DELIVERED scan has a fixed version.
G2  Undo: the main saved profile keeps ONE previous version (users.saved_profile_prev). It is written in the
    same UPDATE that replaces the profile (save from a scan with different content, or a hand edit), so no
    race can lose it. Settings shows "Earlier version … Restore earlier version"; POST /profile/restore-previous
    swaps the two (so a restore can be undone too), guarded by the replacedAt stamp the page showed (409 if it
    moved). Removing the saved profile, deleting the account, the export, and clear_saved_profile_source all
    cover it. make-main drops it (it was a revision of the profile being swapped out).
