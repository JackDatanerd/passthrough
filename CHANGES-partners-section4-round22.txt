BUG  GET /partners/:id/links replaced the partner's live payout link on every call (the token is stored hashed, so "showing" it

     the dashboard link only. The admin "Copy payout-details link" button (behind its existing confirm dialog) now POSTs
     /partners/:id/regenerate-link {scope:'payout'}, which issues the link, emails the partner the replacement, and returns it.

     payoutUrl and dashboardUrl, and the Edit-partner modal warns and copies both. (No change to the audit-log detail.)
